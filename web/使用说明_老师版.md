# 答题卡生成器 · 网页版使用说明

> 面向不熟悉命令行的老师。全程只用鼠标，双击打开，填表，点按钮出文件。

---

## 一、怎么打开

文件夹里找到 **`打开答题卡生成器.bat`**，双击。

浏览器会自己打开，左边是设置区，右边直接显示答题卡预览，改一个地方预览就立刻变。

如果双击后提示"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行**。

打不开的话，直接双击 `answer_sheet.html` 也可以（右键 → 打开方式 → Microsoft Edge）。

---

## 二、从打开到打印，四步

1. 在左边改标题：把「2026年普通高等学校招生全国统一考试」改成你要的考试名称
2. 选选择题方式：**机读涂卡** 或 **填写答案（表格）**
3. 选 **彩色** 或 **黑白**
4. 点 **生成 PDF 文件**，文件会存到浏览器默认的下载文件夹

然后打开那个 PDF，打印时选 **A3、横向、缩放 100%**，两页正好是一张纸的正反面。

---

## 三、每一项是做什么的

### 标题
- **大标题**：试卷名称，就是你最常改的那一行。文字太长会自动缩小，再长会拆成两行，不会压出边框。
- **副标题**：默认「数学答题卡」，可改成语文、英语等。
- **页脚文字**：`{page}` 和 `{pages}` 会自动替换成页码。

### 选择题方式
| 选项 | 什么时候用 |
|---|---|
| 机读涂卡 | 要上阅卷机扫描，学生用 2B 铅笔涂 A/B/C/D |
| 填写答案（表格） | 人工批改，或者考试不需要扫描，学生直接写 ABC |

**单选题数 / 多选题数** 可以改。表格模式下，多选题那一行的格子会自动做成单选题格子的两倍宽，因为多选要写 `ABD` 这样三个字母。

### 配色
- **彩色**：默认粉色（255,50,165），适合彩色打印
- **黑白**：校内速印用这个，线条在复印件上更清楚
- 上面那排色块点一下就能换主色，也可以自己在「主色」框里填 `255,0,0` 这样的数字

### 解答题分值
15 到 19 题括号里的分数，改数字就行，预览里立刻能看到。

### 答题区插图
八行，对应八个可以贴图的位置：

| 行 | 位置 |
|---|---|
| 第1页 左列（15 题） | 15 题答题框 |
| 第1页 中列上（续 15 题） | 「（续15题）」那一块 |
| 第1页 中列下（16 题） | 16 题 |
| 第1页 右列（17 题） | 17 题 |
| 第2页 左列（18 题） | 18 题 |
| 第2页 中列上（续 18 题） | 「（续18题）」那一块 |
| 第2页 中列下（19 题） | 19 题 |
| 第2页 右列（续 19 题） | 「（续19题）」那一块 |

操作：点「选择文件」挑一张图（立体几何图，PNG 或 JPG 都行），宽度留空就是 4.8 cm，想大一点就填 `6`。图片会贴在答题区右上角，太大时自动等比缩小，不会压出边框。点「清除」可以撤掉。

### 输出
- **清晰度**：默认 200 dpi，老电脑也能跑；300 dpi 更清晰但慢一些、文件大一些。
- **生成 PDF 文件**：主按钮，出 PDF。
- **另存为图片**：万一 PDF 打不开（少数老电脑的 PDF 阅读器有问题），用这个导出两张 PNG，打印时按 A3 横向、100% 缩放也一样。
- **直接打印（A3）**：不走 PDF，直接唤起打印窗口。打印设置里务必选 A3 横向。
- **恢复默认设置**：一键回到出厂状态。

设置会自动记在这台电脑上，下次打开还是上次的样子。

## 四、字体说明

答题卡的字体是固定的：**数字和英文用新罗马（Times New Roman），汉字用宋体，标题用黑体**。这和正式考试答题卡的习惯一致，也是数学试卷最常用的搭配。

如果这台电脑没装新罗马，数字会退回到宋体显示，版面不会乱，只是字形略有不同。Windows 系统一般都自带新罗马，正常情况不用管。

想换成别的西文字体（比如 Arial），改 `config.json` 里的 `fonts.latin` 即可，中文部分不受影响。

## 四、学校 Windows 7 电脑能用吗

**不用装 Python，不用装 LaTeX，不用联网。**

要求只有一条：浏览器要支持画布功能。具体来说：

| 浏览器 | 情况 |
|---|---|
| Microsoft Edge | 推荐，Win10/11 自带 |
| Google Chrome | 任意较新版本都行 |
| 360 / QQ 浏览器 | 需要切到「极速模式」（地址栏右边有个闪电或 e 图标） |
| Windows 7 自带的 IE11 | **不能直接用**，页面会显示提示。请装一个 Chrome 或用 360 极速模式 |

页面检测到浏览器太旧时，会直接用大字给出上面的提示，不会白屏。

## 五、常见问题

**改了标题，预览没变？**
在输入框里敲完字后按一下 Tab 或者点别处，预览会刷新；也可以直接在框里接着打字，会有轻微延迟刷新。

**PDF 里文字是模糊的？**
PDF 里的字是图片形式（200 dpi 或 300 dpi）。打印 A3 完全够用；如果要在屏幕上放大看，把清晰度调到 300 dpi 再生成一次。

**生成的 PDF 打印出来尺寸不对？**
打印对话框里把「缩放」改成 **100% / 实际大小**，纸张选 A3，方向选横向。选「适合纸张大小」会导致位置偏移，答题框会歪。

**想把文件带到别的电脑用？**
整个 `web` 文件夹拷到 U 盘即可，解压后双击 bat 就能跑，不依赖安装。

**双面打印怎么翻？**
两页是一张 A3 的正反面，双面打印选 **短边翻转（Flip on short edge）**。打出来裁成两半，就是 6 个 A4 面。

## 六、和 Python 版的关系

- `web/answer_sheet.html` —— 网页版，给老师用，只要浏览器
- `answer_sheet.py` —— Python 版，给会命令行的人用，能生成真正的矢量文字 PDF（更小更清晰）
- 两个的版面参数完全一致，同一份配置出来的答题卡是一样的

如果你要在没有浏览器的纯批处理环境里批量出答题卡，用 Python 版；平时手工做一份，用网页版。
